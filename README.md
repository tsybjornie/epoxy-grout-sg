## real-hdb-block-dusk.jpg  — REQUIRED

The hero photograph. Until this file exists, `ScrollJourney` renders a visible
placeholder telling you so; it never silently substitutes a fake.

**Shoot it yourself.** A block is a building someone owns and a photograph of
it is someone's copyright — a stock or image-search grab is a licensing
problem you do not need. Yours costs nothing, and a block you have actually
worked in is the better picture.

- Landscape, from across a carpark or void deck, whole massing in frame
- Around 7pm — sky still holding colour, units lit
- Lit windows are the point: they make the image read as inhabited
- Export ~2400px wide, JPEG quality 80, aim under 400 kB
